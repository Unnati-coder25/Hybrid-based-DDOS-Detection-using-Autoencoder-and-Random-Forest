## 1. Project Overview

This project implements a hybrid Machine Learning
and Deep Learning approach for detecting
Distributed Denial of Service (DDoS) attacks.

It combines an Autoencoder for dimensionality
reduction and anomaly representation with a
Random Forest classifier for network traffic
classification.

The system is trained and evaluated using
the CIC-DDoS2019 dataset.

## 2. Problem Statement

DDoS attacks attempt to overwhelm network
resources by generating large volumes of
malicious traffic.

Traditional detection approaches may struggle
with complex traffic patterns and previously
unseen attack behaviour.

This project explores a hybrid learning approach
to improve malicious traffic detection.
